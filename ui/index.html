Cryptarithm Mathematical Rules

Mathematical constraints, domain rules, and CSP search principles.

Foundational Rules

1. Bijection: Each letter uniquely represents a single decimal digit from 0 to 9. Two different letters cannot share the same digit.

2. Non-Zero Leading Letters: The first letter of any multi-letter word cannot be zero (e.g. In SEND, S ≠ 0).

3. Base-10 Alphabet Limit: Because base-10 arithmetic uses digits 0–9, an equation can contain at most 10 distinct letters.

4. Interlocking Characters: Addends must share letters with each other or the result to form a constraint network.

CSP Search Algorithms

• Basic Backtracking: Explores variable assignments in arbitrary textual order, only validating arithmetic when all variables are filled.

• MRV (Minimum Remaining Values): Prioritizes variables with the tightest constraints (units column and leading letters), dramatically cutting search space.

• Forward Checking (FC): Prunes the domains of remaining variables each time an assignment is made and immediately detects column carry contradictions.
